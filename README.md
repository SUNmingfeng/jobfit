# JobFit - 简历JD智能匹配分析器

一个智能Chrome浏览器插件，调用 **Kimi AI** 分析简历与BOSS直聘职位JD的匹配度，提供详细的匹配报告和优化建议。

## ✨ 核心功能

- 📄 **简历智能解析**：上传PDF/DOC/DOCX简历，Kimi AI自动提取关键信息
- 🔍 **BOSS直聘集成**：自动识别BOSS直聘职位页面，提取职位信息
- 🤖 **AI匹配分析**：调用Kimi API深度对比简历与职位要求
- 📊 **可视化结果**：圆环进度条展示匹配度百分比
- ✅ **匹配项分析**：详细列出匹配的项目和匹配度
- ❌ **缺失项提醒**：清晰展示不匹配或缺失的技能要求
- 💡 **优化建议**：AI生成针对性的简历优化建议
- 💾 **智能缓存**：简历解析结果缓存7天，避免重复解析

## 🚀 快速开始

### 1. 配置API密钥

编辑 `config.js` 文件，填入您的Kimi API密钥：

```javascript
KIMI_API_KEY: 'sk-your-actual-api-key-here'
```

> 获取API密钥：[Moonshot AI平台](https://platform.moonshot.cn/)

### 2. 安装插件

1. 打开Chrome浏览器，访问 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `jobFit` 文件夹

### 3. 开始使用

1. 访问 [BOSS直聘](https://www.zhipin.com) 任意职位详情页
2. 点击浏览器工具栏的 **JobFit** 图标
3. 上传您的简历（PDF或Word格式）
4. 等待简历解析完成（Kimi AI自动提取关键信息）
5. 点击"开始分析匹配度"
6. 查看AI生成的匹配报告

## 📋 详细使用流程

### 第一步：打开职位页面
- 必须在BOSS直聘职位详情页使用（URL格式：`https://www.zhipin.com/web/geek/job...`）
- 如果不是BOSS直聘页面，插件会提示"无法获取职位信息"

### 第二步：上传简历
- 支持点击选择文件或拖拽上传
- 支持格式：PDF、DOC、DOCX
- 简历内容会被发送到Kimi API进行解析
- **解析结果会缓存7天**，期间无需重复上传

### 第三步：开始分析
- 插件自动提取页面职位信息
- 调用Kimi API对比简历与职位要求
- 生成详细的匹配度分析报告

### 第四步：查看结果
- **匹配度百分比**：直观显示整体匹配程度
- **匹配的项目**：列出您符合要求的技能和经验
- **不匹配的项目**：指出需要改进的地方
- **优化建议**：AI给出的简历改进建议

## 🔧 配置选项

在 `config.js` 中可以修改以下配置：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `KIMI_API_KEY` | - | **必填** Kimi API密钥 |
| `KIMI_MODEL` | moonshot-v1-8k | Kimi模型版本 |
| `SESSION_MAX_AGE` | 7天 | 简历缓存有效期 |

## 🎯 技术实现

### 简历解析流程

```
用户上传简历 → PDF.js/Word库提取文本 → Kimi API解析 → 结构化数据 → 本地缓存
```

### 匹配分析流程

```
提取BOSS职位信息 → 调用Kimi API对比 → 生成匹配度/匹配项/建议 → 可视化展示
```

### 缓存机制

- 简历解析结果存储在 `chrome.storage.local`
- 缓存有效期7天（可配置）
- 上传新简历自动清理旧缓存

## ⚠️ 注意事项

1. **必须使用BOSS直聘页面**：插件仅支持BOSS直聘职位详情页
2. **需要API密钥**：使用前必须配置有效的Kimi API密钥
3. **网络要求**：需要联网调用Kimi API
4. **API费用**：Kimi API调用会产生费用，请注意使用额度

## 🐛 常见问题

### Q: 提示"无法获取职位信息"
**A**: 请确保：
- 当前页面是BOSS直聘职位详情页
- URL格式为 `https://www.zhipin.com/web/geek/job...`
- 页面已完全加载

### Q: 简历解析失败
**A**: 
- 确保PDF是文本型而非扫描版图片
- 检查文件是否加密
- 尝试使用Word格式简历

### Q: API调用失败
**A**: 
- 检查 `config.js` 中的API密钥是否正确
- 确认网络连接正常
- 检查Kimi API账户余额

### Q: 如何清除缓存？
**A**: 
- 点击简历旁的"删除"按钮
- 或上传新简历自动覆盖旧缓存

## 🔒 隐私说明

- 简历文本会发送到Kimi API进行解析
- 分析结果仅保存在本地浏览器
- 不会收集或上传任何个人信息到第三方服务器
